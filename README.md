# Radiant Publications

This is the public research index of the **Radiant Institute for Manifold Studies**.

The authoritative scholarly records are the linked arXiv records below. The institute pages provide public context and citation information. This repository deliberately does not mirror paper PDFs, source archives, datasets, experimental artifacts, or private research materials.

## Preprints

### Allostatic Control Systems: Goal Governance in Changing Environments

Thomson D. Nguy. 2026. [arXiv:2607.21771](https://arxiv.org/abs/2607.21771) [eess.SY; cross-list cs.SY].

- Institute record: <https://www.theradiantinstitute.org/preprints/allostatic-control-systems>
- Public PDF: <https://arxiv.org/pdf/2607.21771>
- Scope: a two-timescale engineering problem of goal governance when an existing goal becomes inappropriate as an environment changes.
- Result boundary: includes a preregistered negative result; it is an arXiv preprint, not peer reviewed.

### More Context, Same Budget: Dual-Bounded Relational Recall Beyond Top-K Retrieval

Thomson D. Nguy. 2026. [arXiv:2608.18448](https://arxiv.org/abs/2608.18448) [cs.IR; cross-list cs.CL].

- Institute record: <https://www.theradiantinstitute.org/preprints/more-context-same-budget>
- Public PDF: <https://arxiv.org/pdf/2608.18448>
- Scope: complete supporting-evidence recovery under a frozen HotpotQA FullWiki retrieval design.
- Result boundary: the reported result concerns supporting-evidence recovery, not answer accuracy or general superiority to retrieval systems. It is an arXiv preprint, not peer reviewed.

## Release posture

Each public work is released on its own evidentiary and disclosure boundary. A publication listing does not imply that executable code, datasets, source archives, replication packages, peer review, external validation, or a broader product claim has been released.

When a separately governed public artifact is ready, it will be linked from the relevant paper record.
